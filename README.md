# AIRush — 数据库管理智能体平台

面向企业客户的 SaaS 多租户数据库管理智能体平台：智能运维管理 + 巡检与合规。
支持 MySQL 协议族、PostgreSQL 协议族与达梦，客户侧 Connector 反向隧道接入。

**当前阶段**：设计与规划（Stage 0 尚未开始编码）。
